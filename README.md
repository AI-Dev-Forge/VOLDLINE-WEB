# VOIDLINE — CS2 companion landing page

A responsive, animated, no-build static website concept using HTML, CSS, and vanilla JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For a local server, run `python -m http.server 8000` in this folder, then visit `http://localhost:8000`.

## Before publishing
- Replace the placeholder download URL `https://example.com/download` in `index.html`.
- Update version, product name, features, documentation, support, and privacy links.
- The module cards and metrics are visual placeholders, not real product integrations.
- Use only legitimate, permitted functionality. Do not advertise features that violate a game's rules or enable unfair multiplayer advantages.
- The Google Fonts import requires an internet connection; system fallback fonts are defined.
- Deploy as a static site to Netlify, Cloudflare Pages, or GitHub Pages.

## Files
- `index.html` — page structure and copy
- `style.css` — responsive visual design and animation
- `script.js` — scroll reveals, custom cursor, mobile menu, hero parallax
